Parâmetro de Instabilidade α — NBR 6118:2023, 15.5.2

α = Htot · √(Nk / (Ecs·Ic))
Comparação com α₁: se α < α₁ → nós fixos; se α ≥ α₁ → nós móveis.
α₁ = 0,2 + 0,1·n (n ≤ 3) | α₁ = 0,6 (n ≥ 4) | α₁ = 0,7 (pilar-parede) | α₁ = 0,5 (pórtico)

Estabilidade Global — γz — NBR 6118:2023, 15.5.3

γz = 1 / (1 − ΔMtot,d / M1,tot,d)
ΔMtot,d = Σ(Pd · uh,h)
M1,tot,d = momento de tombamento
Validade: γz ≤ 1,30
